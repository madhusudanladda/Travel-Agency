# 🌍 Travel Agency GUI Application – Java Swing

A desktop-based Travel & Tour Booking Management System developed using **Java (Swing & AWT)** with **file handling** for data storage. This system enables users to register, login, explore destination packages, and book travel, while administrators can manage users, destinations and package data.

---

## ✨ Features

### 👤 User Features
- Secure Login & Signup
- Password Recovery (Security Question Based)
- View & Book Travel Packages
- Profile and booking details stored securely
- Real-time UI response using Swing

### 🛡 Admin Features
- Admin Authentication
- Add / Update / Delete destinations and packages
- Manage registered users
- Access stored data via text-based file system
